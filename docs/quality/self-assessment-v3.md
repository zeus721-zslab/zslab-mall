# 자체 품질 평가 v3 — 최종 점수 90.2

이 문서는 외부 기관의 평가가 아니라 **자체 평가** 결과입니다. 목적은 점수 자체가 아니라 이 프로젝트가 "실제로 운영된다"고 가정했을 때 어느 수준인지 판단하는 것입니다.
채점은 Claude 기반 에이전트가 영역별로 나눠 했고, 1차 심각도 배정은 외부 검토 1회를 거쳤습니다. 평가 기간은 2026-10-07 ~ 2026-10-08입니다.
평가 원자료(영역별 발견 사항 · 회차별 채점표 · 근거)는 저장소 밖에 보관합니다.

## 2. 평가 기준 요약

- 영역별 100점에서 시작해 발견 사항의 심각도만큼 감점합니다(하한 0). 영역 점수 × 배점/100을 더해 총점을 냅니다(소수 1자리).
- 발견 사항은 근거(재현 절차 · 파일:줄 · 명령 출력)가 있는 것만 기록하고, 사용자·운영자에게 미치는 영향으로만 판단합니다.

| 심각도 | 정의(예) | 감점 |
|---|---|---|
| 치명 | 타인 계정·데이터 탈취, 결제·주문 불가, 데이터 유실 | −25 |
| 높음 | 인증 없이 내부 시스템 노출, 핵심 흐름에서 사용자가 막힘, 장애 시 복구 수단 없음 | −10 |
| 중간 | 오류를 엉뚱하게 표시해 혼란, 우회 가능하지만 불편, 운영자가 수작업으로 메워야 함 | −4 |
